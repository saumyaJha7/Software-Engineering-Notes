# Software Engineering Notes

My personal notes on software engineering, concepts broken down into an easy-to-understand way, with lots of diagrams and visual explanations.

These are things I pick up while learning, building and breaking stuff. Nothing here is meant to be perfect or final. It is just how I understood a topic at a point in time.

I'll keep adding to these notes as I learn more.

Enjoy exploring!

## What's inside

- **2. Area** - the actual notes, grouped by topic. Everything from backend fundamentals and system design to frontend, networking, Docker and mobile dev.
- **3. Resources** - links, libs, blogs and advice I want to keep around.
- **LEARNINGS** - takeaways from talks, mentoring sessions and interviews.
- **excalidraw** - the diagrams referenced across the notes.

Some of the areas covered so far:

- **Backend** - first principles, Node, databases, caching, task queues, error handling, security and scaling
- **System Design** - databases, caching, async processing, resiliency, scaling and essentials like consistent hashing
- **Frontend** - React, custom hooks, Zustand and CSS
- **NextJS** - routing, server actions, auth and payments
- **TypeScript & JavaScript** - fundamentals, generics, async JS and the internals
- **Computer Networks** - HTTP, TCP/UDP, DNS and the stuff that actually makes the internet tick
- **Docker & Deploy** - containers, images and getting things shipped
- **Mobile Dev** - React Native, navigation, sensors and system APIs
- **Redis, Pydantic, AWS & more**

## How I write these

Most notes follow a simple flow: what it is, why it exists, and how to actually use it. Diagrams do the heavy lifting wherever words get too wordy.

If something here is wrong or outdated, that's on me learning. Corrections are always welcome.

**Want to contribute?** If there's a topic you'd like to add that isn't covered yet, feel free to raise a PR.
