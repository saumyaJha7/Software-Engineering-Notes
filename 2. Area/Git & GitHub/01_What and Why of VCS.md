## Q. What is git ?

### Ans. Git is a VCS i.e. a software that tracks the code's progress ,  it is like checkpoints in game .


## Q. Why is git ?
- Tracks changes in source code over time
- Allows multiple developers to work on the same project
- Lets you go back to previous versions of code
- Works **locally on your computer**


## Q. Git vs Github ?

| Feature           | Git                    | GitHub                           |
| ----------------- | ---------------------- | -------------------------------- |
| Type              | Version control system | Hosting & collaboration platform |
| Usage             | Manages code locally   | Hosts code remotely              |
| Internet required | ❌ No                   | ✅ Yes                            |
| Main purpose      | Track code changes     | Share & collaborate on code      |
| Alternatives      | —                      | GitLab, Bitbucket                |

## Simple Analogy

- **Git** = Camera 📸 (takes snapshots of your code)
- **GitHub** = Cloud storage ☁️ (stores and shares those snapshots)
