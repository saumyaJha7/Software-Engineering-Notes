## Q. Problem before react ?
### Ans:- 

- DOM manipulation was messy .
- jab ek click se 4 jgh UI change krna ho to error hone ke chances hai 
- kyuki sb manually krna pdta hai 



## Q. Solution ?
### Ans:-  React : A JavaScript ==library== that builds UI using components and keeps UI in sync with data.

- UI = function(state/data)
- you change the state , react will handle the UI changes
- it is component based lib ( small , reusable piece of code )

### Ans :- 


- speed and  performance ( SPA over reloading every time )
