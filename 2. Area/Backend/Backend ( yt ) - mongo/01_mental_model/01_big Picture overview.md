## Flow :-
1. Frontend banao 
2. Api se req kro backend pe
3. Backend mai routes handle kro 
4. Db ka kaam also backend mai


## File structure in  backend :-
1. DB : for actual db connection logic
2. Models : schemas
3. Controllers : Functionality ( kya krna hai jab req aaye /users pe)
4. Routes : iss route pe ye fn/controller call kro , usme ye etc
5. MiddleWares : for middleWares like auth mayBe
6. Utils : Utilities = Utilities jo baar use kroge like  Mail bhjna , message wala , file upload krne ki
