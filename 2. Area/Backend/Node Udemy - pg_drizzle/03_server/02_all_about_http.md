## Q. What are HTTP methods ?
### Ans : HTTP method yeh batata hai ke client (browser ya app) server se kya _karwana chahta hai_ , like delete , read etc.


## Q. State different HTTP methods ?
### 1. Get : to get the data ==*( get this month expense )*==
### 2. Post : to send data  ==*( new expense add )*==
### 3. Put : pura data replace krdo with new data ==*(  ? ) ==*

## Q. What is HTTP status code ?
### Ans. Server jab response bhjta hai to client ko status btane ke liye 3 digit number use krta hai , wahi hai status code ==( status could be all good , some data is missing , kch galat req hai)==


## 🔸 **Status Codes ke Types **

|**Code Range**|**Category**|**Meaning**|
|---|---|---|
|**1xx**|**Informational**|Request receive hui, process ho rahi hai|
|**2xx**|**Success**|Request successful thi|
|**3xx**|**Redirection**|Resource kahin aur move ho gaya|
|**4xx**|**Client Error**|Client ki galti (wrong request, missing data, etc.)|
|**5xx**|**Server Error**|Server ke end pe problem hui|
