## Q. What is a server ?
### Ans :  A 24/7 running machine with public IP that serves to  other computer's known as client .

![server_101](../../../../excalidraw/server_101.md)


## When client requests some thing , server listens to the request , do something ( db call , auth , etc ) and return back the response to the client .

### In the case of a **web server**, it specifically handles requests for web content — such as HTML pages, images, videos, or other resources — and delivers them to clients (usually web browsers) over the internet using the **HTTP or HTTPS** protocols.



### **Example:**
- You open your browser and type `www.example.com`.
- Your browser (client) sends a request to the web server hosting that website.
- The web server responds by sending back the requested web page.
- Your browser displays it to you.
