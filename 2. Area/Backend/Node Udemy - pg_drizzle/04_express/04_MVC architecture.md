## Q. What is MVC ? 
### Ans : It’s a **design pattern** (or architecture) used to **organize code** in web applications. It stands for Model-View-Controllers .

### It separates your app into **three logical parts**:

1. **Model** → Data 
2. **View** → UI  like html , css , react etc etc
3. **Controller** → Handles requests & connects model + view

## Think of it like :-
1. View : What user sees 
2. Controller : What needs to be done when user req something ( auth , CRUD op)
3. Model : db entity


## Q. Why MVC ?  
### Ans : To keep your code organized, maintainable, and scalable  by separating **data handling**, **user interface**, and **control logic**.
