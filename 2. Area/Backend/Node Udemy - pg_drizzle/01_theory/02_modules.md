## Q. What is a module ?
## Ans. Module is a re-usable piece of code , like a file or function , which we can  import or export into other files !



## There are 3 types of modules :-

#### 1. built-in modules : nodejs ke modules like fs 
#### 2. 3rd party modules : koi aur dev ke modules ( npm i ..  )
#### 3. Custom modules : like any file aur function
