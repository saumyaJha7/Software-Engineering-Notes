## Q. What is Node js ?
### Ans. It is a runtime env. for JS jo browser ke bahar bhi execute krne deta hai js .



## Q. Difference between browser and nodejs ?
## Ans. all js you can run using nodejs except jo browser se related hai i.e. jo native js ka part ni hai , balki web api ka part hai like window mai jo bhi aate hai ( addEventListener , fetch , alert etc) , because node js bana hi **server side** ke liye hai na ki **client side / browser ke liye** 




### - What this "npm init" command does  : 

#### 1. creates a package.json file which is basically a blueprint or in short an imp note about your project like :- 
            a. Project's Meta-data : name , version etc
            b. Dependency : (things needed to run the app)
            c. Scripts : defines shortcut commands 
#### 2. node_modules : isme saare 3rd party dependencies ka source code rhta hai 



```
kch jaadu nahi hai , jb bhi npm i package_name krte ho , github se source code download hoke node_modules mai jaata hai , and then wo package is usable.
```
