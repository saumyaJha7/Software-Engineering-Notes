## Q. What is DB ?
### Ans. Any persistent  ( program khtm hone ke baad bhi data rkhe ) storage 



## Q. Different types of DB ?
### Ans. Two different types based on storage :- 


#### 1. Disk Based Storage ( hdd/sdd ) : 
	- more time ( I/O op )
	- speed less
	- space more 
	- cheap


#### 2. In memory / RAM storage : 
	- fast 
	- space less
	- costly




### Two different based on types :- 

#### 1. Relational 
	- tables 
	- predefined schema 
	- adv : data integrity 

#### 2. Non - Relational 
	- not structured 
	- less data intergrity 
	- adv : flexibility
