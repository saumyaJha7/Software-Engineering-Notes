# "Remember this , ReST API's are planned/designed first then coded"



## Steps to follow while building ReST API :- 

#### 1. DB design : have fixed up this first 
#### 2. Design user flow 
- wireframes to understand how user will interact.
#### 3. From wireframes , find out resources/nouns like 
- users , projects , tasks etc




## Actionable CTA :- 

##### 1. use tools like swagger api or openAPI for docs 
##### 2. make it consistent and intutive 
##### 3.  provide sane defaults 
- pagination 
- sort 
- req fields only like status = active , whenever an org is created by default ofc

##### 4. Avoid abbrevations , like desc or phNo .
