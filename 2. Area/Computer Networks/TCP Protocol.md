## 1. What is TCP ?
### Ans : It is a **core protocol of the Internet** used for sending data between computers reliably. It **works with IP (Internet Protocol)** — together called **TCP/IP**, which is the foundation of the Internet.


## 2. What is the concept of TCP .. why to use it ?
### It ensures that the **all data** sent by the sender is properly gets tfr to the receiver w/o being corrupted or lost !


### 3. How TCP does that?

TCP ensures that when data is sent from one computer to another:
1. The data is **broken into small packets**.
2. Each packet is **numbered** so the receiver can put them back in the correct order.
3. **All packets are delivered** — if any packet is lost, TCP will **ask for it to be resent**.
4. Data arrives **without errors** and in the right sequence.

> In short: TCP makes Internet communication **reliable and orderly**.


## 4. Where it is used :  anywhere where **reliable data delivery** is required like Web browsing , Emails , File Transfers etc ...
