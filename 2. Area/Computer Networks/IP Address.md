# What is IP ?
## It is a network layer protocol whose main job is to  **deliver packets from a source device to a destination device across networks** using **IP addresses**.


## Q. What is IP address? 
### Ans : It is a **unique numerical label assigned to each device** connected to a network (like the Internet).Purpose  is to  **Identify devices and allow them to communicate** with each other. 


## The structure of IPV4 is x.x.x.x  , where each x -> 0-255
