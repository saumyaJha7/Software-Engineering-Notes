## Q. What is Circuit switching ?
### Ans : A **dedicated** communication path (circuit) is established between two devices for the **entire duration** of the communication session.


### How it works is :-
- Like a traditional telephone call: once a call is set up, a fixed path is reserved between the caller and receiver.
- No one else can use that path until the call ends.

## Key Features :-
###  1. Continuous, reserved bandwidth.
### 2. Low latency once the circuit is established.
### 3. Inefficient for bursty data (wastes resources when no data is sent).



### **Example:** Public Switched Telephone Network (PSTN).


### **Quick Analogy:**
- **Circuit Switching** = A dedicated train track from city A to city B (only one train can use it during the trip).
- **Packet Switching** = Many cars (packets) on a road network, each finding its own path to reach the same destination.
